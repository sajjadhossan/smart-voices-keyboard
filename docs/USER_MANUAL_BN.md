# 📖 স্মার্ট ভয়েস কীবোর্ড - ব্যবহার নির্দেশিকা (User Manual)
প্রণেতা: সাজ্জাদ হোসাইন (Sajjad Hossan)
সংস্করণ: ১.০.০ (Version 1.0.0)

## ১. পরিচিতি
স্মার্ট ভয়েস কীবোর্ড হলো অ্যান্ড্রয়েড, উইন্ডোজ ও ম্যাকওএস-এর জন্য একটি আধুনিক ক্রস-প্ল্যাটফর্ম ভয়েস টাইপিং ও এআই অনুবাদ কীবোর্ড। এতে সম্পূর্ণ বিনামূল্যের স্পিচ-টু-টেক্সট ইঞ্জিন, গুগল জেমিনাই এআই অনুবাদ, আনলিমিটেড ক্লিপবোর্ড এবং খাঁটি বাংলা, ইংরেজি ও বাংলিশ ফোনেটিক টাইপিং সুবিধা রয়েছে।

---

## ২. মূল সুবিধাসমূহ

### ক. ভয়েস টাইপিং (Speech-to-Text)
- সম্পূর্ণ বিনামূল্যে বাংলা এবং ইংরেজি ভাষায় কথা বলে দ্রুত টাইপ করার সুবিধা।
- উচ্চমানের ইন্টারিম রিয়েল-টাইম ট্রান্সক্রিপশন।
- কথা শেষ হওয়ার সাথে সাথে সক্রিয় সফটওয়্যার বা অ্যাপে (যেমন MS Word, WhatsApp, Notepad, Browser) অটো-পেস্ট করার সুবিধা।

### খ. লাইভ অনুবাদ ও এআই কমান্ড (Gemini AI)
- **ইংরেজি থেকে বাংলা**: যেকোনো ইংরেজি লেখা এক ক্লিকে বা ভয়েস কমান্ডে শুদ্ধ বাংলায় রূপান্তর।
- **বাংলা থেকে ইংরেজি**: বাংলা থেকে আন্তর্জাতিক মানের সাবলীল ইংরেজিতে অনুবাদ।
- **এআই ভয়েস কমান্ড**: "Make formal", "Fix grammar" বা "Summarize" জাতীয় কমান্ড দিয়ে যেকোনো টেক্সট পরিমার্জন।

### গ. বাংলিশ টু বাংলা ফোনেটিক টাইপিং
- রোমান হরফে টাইপ করলেই তা খাঁটি বাংলা ইউনিকোডে রূপান্তরিত হবে।
- উদাহরণ:
  - `ami bangla bhalobashi` ➔ `আমি বাংলা ভালোবাসি`
  - `dhonnobad` ➔ `ধন্যবাদ`
  - `kemon acho` ➔ `কেমন আছো`
  - `shonar bangladesh` ➔ `সোনার বাংলাদেশ`

### ঘ. আনলিমিটেড ক্লিপবোর্ড ম্যানেজার (Clipboard Manager)
- আপনি যেকোনো অ্যাপ থেকে যা কিছু কপি করবেন, তা স্বয়ংক্রিয়ভাবে লোকাল ডাটাবেজে জমা থাকবে।
- গুরুত্বপূর্ণ টেক্সট পিন (★) করে রাখা যায়।
- সার্চ বক্সে কিওয়ার্ড লিখে তাৎক্ষণিক যেকোনো পুরাতন কপি করা টেক্সট খুঁজে বের করে পেস্ট করা সম্ভব।

## ৩. উইন্ডোজ ও ম্যাকওএস-এ ব্যবহার বিধি

### গ্লোবাল শর্টকাট কীসমূহ:
1. **ভয়েস পপআপ চালু/বন্ধ**: `Ctrl + Alt + Space` (ম্যাকে `Cmd + Alt + Space`)
2. **ক্লিপবোর্ড হিস্ট্রি ওপেন**: `Ctrl + Alt + V` (ম্যাকে `Cmd + Alt + V`)
3. **সরাসরি অনুবাদ**: `Ctrl + Alt + T` (ম্যাকে `Cmd + Alt + T`)

### ব্যবহারের ধাপ:
1. যেকোনো সফটওয়্যারে কাজ করার সময় `Ctrl + Alt + Space` চাপলে স্ক্রিনে সুন্দর একটি ভাসমান (Floating) উইন্ডো আসবে।
2. মাইক আইকনে ক্লিক করে বাংলায় কথা বলুন।
3. কথা শেষ হলে **"টাইপ করুন (Paste into Active App)"** বাটনে ক্লিক করলে তা সরাসরি আপনার কার্সরে টাইপ হয়ে যাবে।
4. সেটিংসে গিয়ে বিনামূল্যে সংগৃহীত আপনার **Gemini API Key** যুক্ত করুন।

## ৪. অ্যান্ড্রয়েড ফোনে ইনস্টল ও সেটআপ

1. গিটহাব রিলিজ থেকে `SmartVoiceKeyboard-v1.0.0-android.apk` ফাইলটি ডাউনলোড ও ইনস্টল করুন।
2. অ্যাপটি ওপেন করে **"কীবোর্ড সক্রিয় করুন (Enable Keyboard)"** বাটনে চাপ দিন।
3. সিস্টেম সেটিংস থেকে `Smart Voice Keyboard` চালু করুন।
4. এরপর **"ডিফল্ট কীবোর্ড নির্বাচন করুন"** বাটনে চেপে স্মার্ট ভয়েস কীবোর্ড সিলেক্ট করুন।
5. যেকোনো মেসেঞ্জার বা ব্রাউজারে টাইপ করার সময় কীবোর্ডের উপরের টুলবার থেকে:
   - 🎙️ ভয়েস বাটনে চাপ দিয়ে কথা বলে টাইপ করুন।
   - ⌨️ বাটনে চাপ দিয়ে ইংরেজি, বাংলা ও বাংলিশ মোড পরিবর্তন করুন।
   - 🌐 বাটনে চাপ দিলে সিলেক্ট করা টেক্সট সাথে সাথে অনুবাদ হয়ে যাবে।
   - 📋 বাটনে চাপ দিলে পূর্বের সকল ক্লিপবোর্ড রেকর্ড দেখতে পাবেন।

## ৫. সমস্যা সমাধান ও সহায়তা (Troubleshooting)

- **ভয়েস শুনতে পাচ্ছে না**: মাইক্রোফোনের পারমিশন নিশ্চিত করুন। উইন্ডোজ/ম্যাকে মাইক্রোফোন প্রাইভেসি সেটিংসে অ্যাপকে পারমিশন দিন।
- **অনুবাদ কাজ করছে না**: আপনার Gemini API Key সঠিক কি না সেটিংসে গিয়ে "টেস্ট করুন" বাটনে যাচাই করুন।
- **বাংলা যুক্তাক্ষর ঠিকমতো আসছে না**: নিশ্চিত করুন কীবোর্ডটি 'বাংলিশ (Phonetic)' মোডে আছে এবং সঠিক বানানে টাইপ করছেন।
